# Bank — симулятор банковских переводов

Пет-проект для отработки конкурентного программирования (Lock, JMM, deadlock-free дизайн), generics и, на поздних этапах, SQL-персистентности и REST API.

## Стек
- Java 21
- Maven
- JUnit 5 (тесты)
- Checkstyle (уже подключён в pom.xml)

## Scope v1 (in-memory)
Многопоточная система переводов между счетами в памяти. Без БД, без REST/UI — фокус на бизнес-логике, потокобезопасности и тестах.

## Запуск
```
mvn test
```
