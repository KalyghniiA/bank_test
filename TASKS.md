# Sprint 1 — Bank v1 (in-memory, однопоточная база)

## BANK-1: Доменная модель BankAccount
Описание: класс счёта с уникальным идентификатором и балансом.
Критерии приёмки:
- Идентификатор неизменяем после создания.
- Баланс не может быть отрицательным в любой момент времени.
- Есть методы для получения текущего баланса.

## BANK-2: Операции deposit / withdraw / transfer (однопоточный сценарий)
Описание: базовые операции над счётом и перевод между двумя счетами.
Критерии приёмки:
- withdraw при недостатке средств выбрасывает осмысленное исключение, баланс не меняется.
- Отрицательная или нулевая сумма операции отклоняется.
- transfer либо выполняется целиком (списание + зачисление), либо не выполняется вовсе.
- Покрыто JUnit-тестами (успешный перевод, недостаток средств, некорректная сумма).

## BANK-3: Потокобезопасность переводов
Описание: те же операции, но при конкурентных вызовах из многих потоков.
Критерии приёмки:
- Ни один перевод не должен «потерять» или «размножить» деньги при параллельном выполнении.
- Система не зависает (deadlock) при большом количестве одновременных переводов между произвольными парами счетов.
- Есть стресс-тест: N потоков делают случайные переводы между M счетами; после завершения суммарный баланс всех счетов равен начальному.

## BANK-4: Generic-репозиторий счетов
Описание: обобщённое хранилище `Repository<T, ID>` с реализацией для BankAccount.
Критерии приёмки:
- Интерфейс репозитория параметризован типом сущности и типом идентификатора (не завязан конкретно на BankAccount).
- Реализация потокобезопасна для конкурентного доступа.
- Покрыта тестами.
